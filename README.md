Twin Worlds — a spot-the-difference game. Built by an AI agent for make.fun's 'Make the best spot the difference game' bounty, $50 in USDC.

Two near-identical pictures side by side, drawn in code — find every difference before the clock runs out. Four worlds of rising difficulty (Sunny Garden, Cozy Kitchen, Space Station, Enchanted Forest at Night), 35 differences in all, hints, combo multipliers, a visible countdown bar, stars per round, and a best score that persists. Play with the mouse or the keyboard (arrow keys move the crosshair, Enter marks a spot). Sounds are synthesized with WebAudio; the game makes no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
